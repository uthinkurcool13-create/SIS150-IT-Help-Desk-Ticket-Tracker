# IT Help Desk Ticket Tracker

A beginner Python project that uses object-oriented programming to create and manage simple IT help desk tickets.

## What the program does

The program allows a user to:

- Create a new help desk ticket
- Assign a priority of Low, Medium, or High
- View all tickets
- Mark a ticket as resolved
- Exit the program

## Python skills demonstrated

- Classes and objects
- The `__init__()` constructor
- Instance attributes
- Instance methods
- Lists
- `while` loops
- `for` loops
- `if`, `elif`, and `else` statements
- User input
- Functions
- f-strings

## How to run it

1. Make sure Python is installed.
2. Download `help_desk_tracker.py`.
3. Run the program from a terminal or Python IDE:

```bash
python help_desk_tracker.py
```

## Example

A user can create a ticket such as:

- Issue: Printer will not connect
- Priority: High
- Status: Open

The ticket can later be marked as resolved.

## Purpose

This project was created as a beginner portfolio project to practice Python programming and object-oriented programming concepts while modeling a simple real-world IT support task.
